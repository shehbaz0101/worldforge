# Day 1 — 2026-09-26

Scaffold for Project B. America/New_York date for this note. No latent
model, trainer, planner, or HTTP API.

## Shipped

- Installable `worldforge` package (`src/` layout), version `0.1.0`, MIT
  license, and a `worldforge` console script. `worldforge version` and
  `python -m worldforge version` print that version.
- Default environment `lotka_volterra`: nondimensional Lotka-Volterra
  predator-prey kinetics with a clipped dose on each species. State
  dimension is 2. `reset(seed)` is deterministic. `step` returns the
  Gymnasium-style tuple without a Gymnasium dependency. `render_ascii`
  prints a one-line population summary.
- Gray-Scott was not chosen. A grid observation is too large for the Day 1
  test budget. The schema still stores a float vector, so a plate can be
  registered later.
- Pydantic trajectory schema: `Observation`, `Action`, `Transition`,
  `Trajectory` (`env_id`, `seed`, `horizon`, transitions). JSON and JSONL
  round-trip. `rollout` records a zero dose or a seeded uniform dose.
- `worldforge env-demo` rolls a short offline episode and prints the
  trajectory summary.
- Unit tests cover determinism, step shapes, the equilibrium, dose sign,
  JSON and JSONL round-trip, and the CLI. No test uses the network. Nothing
  is marked `integration`.
- GitHub Actions runs pytest on Python 3.11 and 3.12 and `ruff check` with
  the `[lint]` extra. Ruff selection is E4, E7, E9, F, and I.
