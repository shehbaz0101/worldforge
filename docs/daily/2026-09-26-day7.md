# Day 7 — 2026-09-26

An HTTP surface over the checkpoint and the Day 5–6 reports, plus
`worldforge serve`. America/New_York date for this note. The server does
not open an outbound connection. No authentication yet.

## Shipped

- `src/worldforge/api/`: FastAPI app at `worldforge.api:app`. Request and
  response models are Pydantic and reject unknown fields. Importing the
  package loads FastAPI and does not load PyTorch.
- `GET /health` returns `status: ok` and the package version.
- `POST /rollout` and `POST /eval/predict` call `open_loop_metrics`. The
  body is a corpus path or a small inline trajectory list, and either a
  checkpoint directory or a seed plus architecture fields. The response
  is `worldforge.predict.v1`. A checkpoint ignores the architecture
  fields. Inline input is recorded as `data: "inline"`.
- `POST /plan` calls `plan_actions` and returns
  `worldforge.action_sequence.v1`. The start is an observation, the first
  observation of a stored episode, or the regulation target when neither
  is sent.
- `POST /eval/plan` calls `planning_regret` and returns
  `worldforge.plan.v1`. Tests use one environment step, horizon 1, and
  two CEM samples.
- `POST /train` calls `train_world_model` on CPU and returns
  `final_train_loss` plus the checkpoint directory. Defaults are 1 epoch,
  1 step, and batch size 1. `epochs` is at most 5 and `steps_per_epoch`
  is at most 8, so a TestClient call stays short. The CLI trainer is
  not capped. `out` omitted creates a temporary directory.
- A missing `ml` extra is HTTP 503. A bad body or a missing path is
  HTTP 422. `rssm` is still rejected when a model is built.
- CLI: `worldforge serve` (`--host`, `--port`, `--reload`). The default
  bind is `127.0.0.1:8000`. The command does not import torch.
- FastAPI and uvicorn are core dependencies, as in ClaimForge. The dev
  extra installs `httpx2` for `TestClient`. Tests are not marked
  `integration`.
- Docs: this note, `PROJECT_STATUS.md`, the README API section, and
  `docs/architecture.md`.

  The default bind is `127.0.0.1:8000`. No outbound call and no API key.
