# Day 3 — 2026-09-26

Encoder and baseline latent dynamics for Project B. America/New_York date
for this note. No training loop, planner, multi-horizon eval CLI, or HTTP API.

## Shipped

- `src/worldforge/models/`: `ModelConfig` (no PyTorch), `Encoder`, `MLPDynamics`,
  `Decoder`, and `WorldModel`. Defaults match Lotka-Volterra (`obs_dim=2`,
  `action_dim=2`, `latent_dim=8`, `hidden_dim=64`). The encoder has two hidden
  layers. The decoder has one. Inputs are floating tensors; modules run in
  float32 on CPU. Leading dimensions are a batch.
- Day 3 dynamics baseline: deterministic residual MLP,
  `z_{t+1} = z_t + mlp(concat(z_t, a_t))`. `build_dynamics` is the extension
  point. `dynamics="rssm"` is reserved for a later stochastic recurrent
  state-space model and raises `NotImplementedError`. It is not implemented.
- `WorldModel.forward` returns `latent`, `next_latent`, `reconstructed`, and
  `predicted_observation`. `predict` is the one-step observation map
  `decode(step(encode(obs), action))`. No optimizer and no loss module.
  `seed` fixes the weights through a private generator and does not leave
  PyTorch's global CPU generator moved. `train()` and `eval()` match; there
  is no dropout.
- Checkpoint directory, format `worldforge.checkpoint.v1`: `config.json`
  (format, package version, `ModelConfig`) and `weights.pt` (`state_dict`
  only). `load_checkpoint` rebuilds on CPU. No secrets and no optimizer state.
- CLI: `worldforge model-info` and `worldforge forward-smoke`. Smoke reads one
  golden-fixture transition or, with no fixture, the coexistence state and a
  zero dose. Dataset commands still import without torch.
- Optional extra `ml` (`torch`, `numpy`). `numpy` is there so a CPU torch
  import does not warn. CI installs the CPU wheel from the PyTorch CPU index
  before the extra, then runs the unit tests. `import worldforge` does not
  import torch.
- Tests cover shapes, parameter counts, seed determinism, train/eval
  agreement, a single backward through one-step MSE (no optimizer step),
  checkpoint round-trip, rejection of a bad checkpoint, the reserved RSSM
  name, a forward over all 48 golden-fixture transitions, and the new CLI.
  Nothing is marked `integration`.

## Failed

- Nothing in the Day 3 scope failed its check. `pytest -m "not integration"`
  passed: 72 tests, on Python 3.12.3. `ruff check .` passed with the existing
  rule selection (E4, E7, E9, F, I). `worldforge model-info` printed the
  residual-MLP baseline, latent width 8, and 10962 parameters, and exited 0.
  `worldforge forward-smoke --fixture tests/fixtures/trajectories --seed 0`
  printed finite tensors with latent shape `(8,)` and predicted shape `(2,)`,
  and exited 0. No network call and no API key during the tests. Torch was
  already installed from the CPU index.
- The training loop was not attempted. `rssm` raises on purpose.
- Python 3.11 was not executed in this environment. CI still runs the suite
  on 3.11 and 3.12.
