# Day 8 — 2026-09-26

Hardening for the Day 7 HTTP API and the CLI paths that read or write a
corpus, a checkpoint, or an output directory. America/New_York date for
this note. WorldForge stays offline. No authentication.

## Shipped

- `src/worldforge/sandbox.py`: user paths resolve inside a data root.
  The root is `--data-root`, or `WORLDFORGE_DATA_ROOT`, or the current
  directory. Relative paths resolve against that root. Absolute paths are
  allowed only when they resolve inside it. `..` and symlinks are resolved
  before the check. A path that leaves the root raises `PathSandboxError`.
  The CLI prints that as an argparse error (exit 2). The API returns
  HTTP 422. A missing file inside the root is still "does not exist".
- Commands that take a path (`collect`, `dataset-info`, `forward-smoke`,
  `train`, `rollout`, `eval-predict`, `plan`, `eval-plan`, `serve`) accept
  `--data-root`. `version`, `env-demo`, and `model-info` do not read a
  user path.
- `POST /train` with `out` omitted creates the checkpoint directory inside
  the data root, not in the system temp directory.
- `src/worldforge/ratelimit.py`: one in-process sliding window for
  `POST /rollout`, `POST /eval/predict`, `POST /plan`, `POST /eval/plan`,
  and `POST /train`, keyed by the client address. The default is 60
  requests per 60 seconds. `WORLDFORGE_RATE_LIMIT` and
  `WORLDFORGE_RATE_WINDOW_SECONDS` change it. `worldforge serve` also
  takes `--rate-limit` and `--rate-window`. Over the limit the response
  is HTTP 429 with `Retry-After` (seconds until the oldest hit leaves the
  window). `GET /health` is not counted. `TestClient` shares one bucket.
- `src/worldforge/offline.py`: importing the API, and `worldforge serve`,
  wrap `socket` connect. A non-loopback TCP target raises `OfflineError`.
  Loopback stays open so the server can accept local clients. The guard
  sets `WORLDFORGE_OFFLINE=1` and does not offer a way to disable itself.
  Optional hub and telemetry variables are set if they were unset
  (`HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE`, `HF_DATASETS_OFFLINE`,
  `WANDB_MODE`, `DO_NOT_TRACK`). None of those libraries are dependencies.
- Pytest writes its temporary directory to `.pytest-tmp` under the current
  directory, so the existing corpus and checkpoint tests stay inside the
  default data root. That directory is gitignored.
- Docs: this note, `PROJECT_STATUS.md`, the README API section, and
  `docs/architecture.md`.
